# VOX-9 ／ 音声討伐

英単語を声に出して正しく発音し、ノイズを討伐していく英単語ゲームです。
ブラウザだけで動きます。インストール不要。

**▶ [プレイする](https://goldfish0824-web.github.io/vox-9/)**

## 遊び方

画面に出た日本語の意味に合う英単語を、声に出して発音します。
正しく調音できた言葉だけが、ノイズを打ち消せます。

- 収録 1200 語
- 苦手単語の記録と復習
- タイムアタック

## 動作環境

| 端末 | 推奨ブラウザ |
|---|---|
| iPhone | Safari |
| Android | Chrome |
| PC | Chrome / Edge |

**LINEなどのアプリ内ブラウザでは音声入力が使えません。**
QRコードやリンクから開いた場合は、メニューから「Safariで開く」を選んでください。

うまく動かないときは、タイトル画面の「マイクの確認」をお試しください。
iPhoneでは「設定 → 一般 → キーボード → 音声入力」がオンである必要があります。
